# DJOneHub QDC507 刷机教程（Windows）

## 准备

1. Windows 10 / 11 电脑。
2. Python 3.8 或更高版本。没装就先去 https://www.python.org/downloads/windows/ 装，
   **安装第一屏必须勾上 `Add python.exe to PATH`**。
3. 一根能传数据的 USB 线（很多线只供电，不行就换一根）。
4. QDC507 模块。

## 操作步骤

1. **解压**：把整个 zip 解压到一个文件夹里。不要在压缩包预览窗口里直接双击。
2. **插模块**：用 USB 线把模块连到电脑，等 10 秒。
3. **双击 `Flash-All.bat`**。刷机只需要这一个文件。
   - 第一次运行会自动联网下载 platform-tools，等 1～2 分钟。
   - 弹「是否允许此应用更改设备」点「是」；出现蓝色 SmartScreen 警告点「更多信息」→「仍要运行」。
4. **确认**：屏幕打印出 `QDC507` 之后，输入 `Y` 回车。
5. **等 2～4 分钟**。不要拔线，不要关窗口。中间模块会自己重启一次。
6. 看到这句就是成功了：

   ```
   全部完成: USB 组合已生效, DJOneHub Agent 已永久部署.
   ```

7. 拔下模块，插到已装好 DJOneHub App 的 iPhone / iPad 上即可使用。

## 报错了怎么办

先重新插拔模块，再双击一次 `Flash-All.bat`。重刷不会刷坏模块。

| 屏幕上出现 | 怎么办 |
| --- | --- |
| 未找到 QDC507 AT 串口 | 换一根能传数据的 USB 线，换个 USB 口（台式机插机箱后面）；仍然不行就装模块的串口驱动 |
| adb 在 120 秒内没有发现模块设备 | 重新插拔，再跑一次 |
| 未找到可用的 Python 3 | 按上面「准备」里的第 2 条装 Python，记得勾 PATH |
| 部署失败 | 直接再跑一次：脚本会先把模块 USB 组合修回 Mac 模式再重试；仍失败就重新插拔再跑 |
| 报错里出现 `usbnet`、`没有 ecm` 或 `作者闸门` | 模块是 usbnet=0 模式：重新插拔模块，再跑一次 `Flash-All.bat`，脚本会自己改成 usbnet=1 再重启 |
| 报错里出现 `模块 shell 未返回退出状态` | 先看窗口里有没有 `部署器构建 2026-10-01`。没有就是在用旧版工具包：重新下载最新版，插拔模块后再跑一次 `Flash-All.bat` |
| 杀毒软件拦截 `deploy-qdc507-agent.py` | 把这个文件夹加入信任区，或先关掉杀毒软件 |

## 恢复原样

- 恢复模块原来的 USB 设置：双击 `Restore-USBConfig.bat`。
- 把 DJOneHub 从模块里彻底删掉：见同目录 `README-Windows.txt` 的「回滚」一节。
