# Windows 刷机工具使用教程

`DJOneHub-Windows-Flasher 0.1.0` 是面向 Windows x64 电脑的 QDC507 首次部署**测试版**。它把设备识别、内置基线包校验、刷写进度和断线重连集中在一个 `.exe` 中，避免让普通用户安装 Node.js 或手动启动网页。

## 适用范围

- 仅支持 Windows 10/11 **x64**。
- 仅允许 USB ID 为 `2c7c:0125` 的 QDC507 模块。
- 仅内置并校验 `0.3.15-first-use` 首次部署基线包；工具不会接受任意本地固件、私钥、降级包或恢复包。
- 仅用于你拥有授权、且尚未部署 DJOneHub Agent 的模块。

如果 iPhone/iPad 或 Mac 客户端已经能查看模块健康状态，请不要使用此工具；应改用客户端中的常规签名 `.djupdate` 更新流程。

## 1. 下载与核对

从项目的 [Windows 测试版 Release](https://github.com/wzz04810-debug/DJOneHub/releases/tag/windows-flasher-v0.1.0-beta) 下载 `DJOneHub-Windows-Flasher-0.1.0-beta.exe`。这是便携版，无需安装；下载后右键查看文件属性并确认来源为本项目 Release。

本测试版尚未进行 Windows 实机矩阵的完整公开验证。Windows SmartScreen 或安全软件提示“未知发布者”是未签名测试包的预期提示，不要关闭安全软件或绕过系统保护；如无法确认来源，请停止使用。

## 2. 连接前准备

1. 使用确认可传输数据的 USB 线把模块直接接入电脑，保持模块供电稳定。
2. 结束模块通话，关闭 ADB、串口工具、DJOneHub 和厂商维护软件。
3. 打开“设备管理器”，只确认 QDC507 的 **ADB 接口**；不要更改网卡、串口、音频等其他复合接口。
4. 仅当 ADB 接口显示为 Class `FF` / Subclass `42` / Protocol `01` 时，才将该接口绑定为 Microsoft WinUSB。无法确认时立即停止。

## 3. 开始刷写

1. 双击运行 `DJOneHub-Windows-Flasher-0.1.0-beta.exe`。
2. 在“内置正式基线”区域点击 `0.3.15` 的“用于刷写”。程序会先读取内置包并校验文件大小、SHA-256 与签名；校验失败时不会显示可刷写版本。
3. 点击“连接 QDC507 并刷写 0.3.15”。
4. 程序只会自动选择一个匹配 `2c7c:0125` 的模块。若未找到或发现多个模块，先只保留一个目标模块再重试。
5. 等待进度完成。安装中出现短暂 USB 断开通常是模块重新枚举，保持供电和连接，等待程序完成验证。

## 4. 完成后验证

1. 程序显示“首次刷写完成”后，再正常拔插模块。
2. 将模块接回 iPhone/iPad 或 Mac，确认 DJOneHub 能读取状态与健康信息。
3. 后续升级使用客户端的正式 `module-update-0.3.21.djupdate`，不要再次使用首次部署工具。

## 5. 出错时怎么做

| 现象 | 处理方式 |
| --- | --- |
| 找不到 QDC507 | 检查数据线、供电与 ADB 接口的 WinUSB 绑定；不要替换整个复合设备驱动。 |
| USB 接口被占用 | 退出 ADB、串口工具、DJOneHub，重新插拔后再试。 |
| 内置包未显示 | 程序发现包文件、大小或 SHA-256 不匹配，已主动停止；重新下载官方测试版。 |
| 刷写中断或验证失败 | 不要重复刷写或断电；使用“复制脱敏日志”保存信息后再排障。 |

## 安全边界

本工具没有私钥、没有任意固件入口、没有无备份降级入口，也不会强行操作非 QDC507 设备。项目和工具仅用于学习、研究与合法的非商业用途；不得用于未经授权的设备访问、侵权、规避安全限制或违反运营商及平台规则的行为。
